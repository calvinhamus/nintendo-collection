# Nintendo Collection

A tracker for three collections: Metroid, HAL Laboratory, and Final Fantasy. Each set has its own tab, completion tracking by system, ownership and condition tracking, prices paid, a wishlist, and export/import for backup. It runs on GitHub Pages with no build step.

## Files

| File | Purpose |
|---|---|
| `index.html` | The tracker page |
| `games.js` | The catalog: sets, systems, and every release |
| `covers.js` + `covers/` | Box art, generated by `scripts/update_covers.py` |
| `.github/workflows/update-covers.yml` | Downloads box art into the repo |
| `prices.json` | Generated by the price workflow; the page runs fine without it |
| `scripts/update_prices.py` | Pulls PriceCharting prices into `prices.json` |
| `price-overrides.json` | Better search strings for games the price script mismatches |
| `.github/workflows/update-prices.yml` | Runs the price script weekly |

## Publish on GitHub Pages

1. Create a repo and push these files to `main`.
2. Open **Settings → Pages → Build and deployment**, set the source to **Deploy from a branch**, and choose branch `main` with folder `/ (root)`.
3. The site goes live at `https://<user>.github.io/<repo>/` within a minute or two.

## Collection rules

**Metroid** covers every physical North American release. Collector variants count as their own entries: Samus Returns Legacy Edition, Dread Special Edition, the Echoes bonus disc, Prime Hunters: First Hunt, Classic NES Series Metroid, and the Prime 4 Switch 2 Edition.

**HAL Laboratory** covers games HAL developed or co-developed on Nintendo systems. Games HAL only published or supervised are left out, including Kirby's Avalanche, the Epic Yarn games, and Smash Bros. from Brawl onward. The NES ports HAL America released (Joust, Millipede, Defender II) are included and flagged.

**Final Fantasy** covers every FF-branded game on a Nintendo system, plus the original North American release of each mainline numbered entry and its direct sequels on any platform. Originals and ports both count. Japanese and Asian Switch releases count as imports, while imports for older systems do not. The PS1 originals of I, II, IV, and V shipped inside Origins, Chronicles, and Anthology, so those compilations stand in for them.

Digital-only and upcoming games stay listed but don't count toward completion. Mark them in `games.js` with a note starting `Digital only` or `Upcoming`, and remove the note when a game releases.

## Your collection data

Ownership, condition, price paid, wishlist, and notes save in the browser's local storage. Use **Export collection** to back up or move to your phone, and **Import collection** on the other device. Commit an export to the repo if you want version history.

## Box art

Covers for older systems come from the libretro-thumbnails project. Switch and Switch 2 covers are the official eShop artwork, looked up through blawar/titledb and shown whole on a blurred backdrop because eShop art is square.

After you push the repo, open **Actions → Update covers → Run workflow**. It downloads every cover into `covers/` and commits it, so the site serves its own images. It tries the eShop art first and Wikipedia's cover art second. Until it runs, the Switch covers load straight from Nintendo's image server and retry with Wikipedia in the browser if that fails. The workflow also reruns on its own whenever `games.js` changes.

Games with no eShop listing yet (Kirby Air Riders, the Switch 2 versions of FF VII Remake, Rebirth, and XIV, and unreleased games) try a Wikipedia image in the browser and otherwise show a placeholder. Add an entry to `ESHOP` in `scripts/update_covers.py` once a game shows up in titledb, and the next run picks it up. Use `OVERRIDES` or `NOMATCH` in the same file to fix a wrong libretro match.

To run it yourself:

```bash
pip install pillow
python3 scripts/update_covers.py
```

## Prices (optional)

Each game's detail sheet links to its PriceCharting search with no setup needed.

For prices on every tile, collection value, and cost to finish:

1. Get a PriceCharting API token (requires their paid plan).
2. Open **Settings → Secrets and variables → Actions → New repository secret** and add the token as `PRICECHARTING_TOKEN`.
3. Open **Actions → Update prices → Run workflow**. It commits `prices.json` and repeats every Monday.

The log lists any game that matched the wrong product. Add a search string for it in `price-overrides.json`, keyed by game id, and rerun.

## Editing the catalog

Each row in `games.js` is `[set, system, title, year, region, note]`. Region is `NA`, `JP`, or `AS`. A game's saved data is keyed by set, system, title, and region, so changing a year or note is safe, but renaming a title resets that game.
